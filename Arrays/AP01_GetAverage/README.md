# AP1 – Get Average

## Problem

Given an integer array, calculate and return the average of all the elements in the array.

## Approach

1. Initialize a variable `sum` to `0`.
2. Traverse through each element of the array and add it to `sum`.
3. Find the size of the array using `arr.length`.
4. Divide the total sum by the number of elements to calculate the average.
5. Return the calculated average.

## Example

### Input

```text
[2, 4, 1, 3, 9]
```

### Output

```text
3.8
```

## Complexity

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)
